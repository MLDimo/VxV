# VXV

Outil de guilde WoW Forever : addon, site, bot Discord et app compagnon.
Conventions et état d'avancement : voir [CLAUDE.md](CLAUDE.md).

| Dossier | Contenu |
| --- | --- |
| `tools/VXV_Probe` | Addon de test de la Phase 0, jamais distribué. |
| `tools/probe-harness` | Fait tourner la sonde hors du jeu (`npm test`) avant chaque installation. |
| `tools/install-probe.sh` | Copie la sonde dans le dossier AddOns d'un client. |
| `tools/write-inbox.sh` | Simule le compagnon pour le test fichiers. |
| `docs/phase-0` | Protocole de test et rapport de faisabilité. |
